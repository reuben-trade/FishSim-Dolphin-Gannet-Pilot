# Supporting timing evidence

These **three engineering checks are separate from the 24 feeding encounters** used in the notebook analysis. They are not additional independent schools or replication samples. All case files, completion seals, protocol amendments and audit receipts are retained.

- Disabled 4T replay: exact agreement with the original baseline.
- Enabled 8T feasibility run: no qualifying local cue at legal bird launch decisions, so no dive was deferred.
- Opportunity-selected 36T demonstration: one partial hold lasting about0.07624T, then cancellation when the bird left the cue locality. There were zero successful requested1T releases, and catches did not increase. This is post-hoc engineering validation, not a fresh timing-benefit test.

Read [REPORT.md](REPORT.md) for the chronology and [INDEX.json](INDEX.json) for the three sealed case locations. `results/lag1_36T_demonstration_v1/demonstration_validation.json`, `demonstration_review.json` and `event_prefix_and_effort_review.json` record the independent checks. Original baseline comparison cases are among the notebook's preserved fresh-replication inputs.

Default notebook verification checks these three support seals and their source closure, but never adds them to pooled feeding outcomes. No native execution is required to inspect the evidence.
