# Crossed follow-up prospective archive

This preserves the accepted native-free design for H1/G12 and H2/G36 on the same16 schools and two nested labels as the existing prospective studies. Native execution remains unauthorised. See the [public plan](../../reports/supplements/CROSSED_FOLLOWUP_PLAN.md).

Exact copied author files: protocol, analysis plan,128 planned identities,4 engineering identities,128 new-case control mappings,64 paired mappings, design freeze, handoff, pure validation summary, timing/resource snapshot and build_design.py. The original author README is SOURCE_README.md. Root acceptance and independent design review are copied byte-exact. SOURCE_FINGERPRINTS.json maps copies to original locations and records reference hashes; some underlying reference inputs remain in existing archives or author provenance rather than being recopied here.

Run `python inspect_inventory.py` from this folder to verify archive hashes and local inventory arithmetic. This uses only the standard library and reads no model or outcomes. The copied build_design.py is archival authoring source with author-path dependencies; this archive does not promise it is a portable execution harness. No native simulator, compiler, model constructors or feeding outputs are included.

The future bank has512 unique full outcomes (384 already planned plus128 new),256 reused unique controls,16 independent school clusters and32 labelled worlds. Engineering cases reuse four case identities at a shorter horizon and do not add independent feeding replicates. Future control completion hashes deliberately remain pending until both source studies pass independent FINAL audits.

POSTING_CONTEXT.json distinguishes prospective design time, primary feeding launch and later public posting. The actual first push confirmation is recorded after success in the dated publication receipt; nothing is backdated and no formal preregistration is claimed. The current paper, notebook and Doc remain unchanged.
